# SAQA — Асық ату

Современная браузерная 2D-адаптация традиционной казахской игры «Асық ату». Проект рассчитан на молодую аудиторию и международного пользователя: интерфейс доступен на русском, казахском и английском языках.

## Что создано

- полноценный игровой раунд с площадкой, 15 асыками и сақа;
- прицеливание мышью или касанием;
- выбор силы броска;
- простая физика движения и столкновений;
- выбивание асыков за пределы игрового поля;
- счёт и понятный финальный результат;
- локальный рекорд;
- «Испытание дня» с альтернативной расстановкой;
- адаптивный интерфейс для компьютера и смартфона;
- раздел с правилами прямо в приложении;
- RU / KZ / EN.

## Для кого

Для школьников, студентов, семей и людей за пределами Казахстана, которые хотят быстро познакомиться с асық ату через интерактивную игру.

## Правила цифровой версии

За основу взят спортивный формат «Асық ату»: официальные материалы описывают ровную площадку, 15 асыков на центральной линии, бросок сақа с отметки 6 м и победу в встрече игрока, который первым выбивает 8 асыков за пределы круга. Также описывается дополнительная попытка с сокращённой дистанции после успешного первого попадания. Источники: официальный материал gov.kz и материалы, ссылающиеся на правила Федерации «Асық ату» Республики Казахстан.

В SAQA сохранены ключевые элементы, но одиночная браузерная игра адаптирована так, чтобы один человек мог пройти законченный раунд:

1. На поле размещаются 15 асыков.
2. Сақа стартует с цифровой отметки 6 м.
3. Игрок наводит прицел и выбирает силу броска.
4. Если сақа сталкивается с асыком, асык считается выбитым, когда покидает круг.
5. Каждый выбитый асық = 1 очко.
6. Цель — выбить 8 асыков.
7. Для понятного браузерного раунда установлен лимит 15 бросков. Если 8 асыков выбиты раньше — игрок побеждает; иначе после 15-го броска показывается итоговый счёт.

### Авторские дополнения

- одиночный формат вместо очной встречи двух игроков;
- лимит 15 бросков для гарантированного финала;
- сенсорное/мышиное управление;
- упрощённая физическая модель;
- «Испытание дня» с другой расстановкой;
- сохранение лучшего результата в `localStorage`;
- мультиязычный интерфейс;
- современная визуальная концепция «летний двор».

## Запуск локально

Требуется Node.js 18+.

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

## AI-инструменты

При разработке использовался **OpenAI ChatGPT** для проектирования игровой концепции, структуры интерфейса, формулировки цифровых правил, генерации и рефакторинга части исходного кода и подготовки README. Визуальная концепция и игровые решения адаптированы под это задание вручную.

## Заимствованные компоненты

Проект не использует сторонние игровые ассеты, фреймворки физики или готовый игровой движок. Графика асыков, сақа, поля и интерфейса отрисовывается кодом приложения. Для типографики используется Google Fonts (Manrope и Unbounded).

## Известные ограничения

- это упрощённая цифровая адаптация, а не электронная версия официального спортивного судейства;
- физика намеренно упрощена и не моделирует все свойства настоящих асыков;
- multiplayer пока не реализован;
- рекорд хранится локально в браузере и не синхронизируется между устройствами;
- «Испытание дня» в текущей версии использует заранее заданную расстановку, а не серверную генерацию.
